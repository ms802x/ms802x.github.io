# Launch checklist

- [ ] Review the sample posts in `src/content/blog/` (all `draft: true`); rewrite or delete them.
- [ ] Optional: enable comments (see README → Sharing and feedback).
- [ ] Optional custom domain: set the `SITE_URL` repository variable and enable **Enforce HTTPS**.
- [ ] Run `npm run check` and `npm run build`, then push to `main`.
